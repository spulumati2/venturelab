# VentureLab
Free static venture-capital learning simulation. No paid API key or build step is required.

## Publish/update on GitHub Pages
1. Extract this ZIP.
2. In your existing GitHub repository choose **Add file → Upload files**.
3. Upload the *contents* of this folder, not the outer folder itself. Keep `index.html`, `styles.css`, and `app.js` at the repository root.
4. Commit the changes to `main`.
5. In Settings → Pages, use **Deploy from a branch**, `main`, and `/(root)`.
6. Wait for the Pages workflow to finish successfully.

## Included
Virtual $10M fund, fictional startup marketplace, ownership calculator, portfolio, quarter simulation, fictional exits, six VC lessons, built-in rule-based mentor, browser save, JSON import/export, responsive layout, and larger text.

The mentor is a built-in learning helper, not a live generative AI service. This is an educational simulation, not investment advice. Progress is stored locally in the browser.
